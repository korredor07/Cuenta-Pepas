# Estilo visual Cloverance para Cuentapepas

Fuente: sitio público de Cloverance (diagnosticoanei.netlify.app), extraído el 2026-10-12. Logo: `cloverance-logo.png` (660×294, verde y blanco, pensado para fondo oscuro).

## Colores (tokens)

| Token | Hex | Uso sugerido |
|---|---|---|
| ink | #010E0B | Barra superior/encabezados oscuros, texto principal |
| ink-soft | #3A4A44 | Texto secundario |
| paper | #F8F7F4 | Fondo de pantalla |
| surface | #FFFFFF | Tarjetas |
| mist | #DFE2DC | Bordes, divisores |
| mist-deep | #AFB6AE | Bordes fuertes, deshabilitado |
| green | #47B914 | Color de marca, acción principal |
| green-deep | #2A700C | Texto/acción sobre fondo claro, estado OK |
| green-tint | #EAF6E4 | Fondo de avisos positivos |
| amber | #B87614 | Advertencias |
| amber-bright | #E09A1E | Énfasis de advertencia |
| amber-tint | #FAF0DC | Fondo de advertencia |
| brick | #9E4B33 | Errores |
| brick-tint | #F5E3DE | Fondo de error |

Sombra de tarjeta: `0 1px 2px rgba(1,14,11,.07), 0 8px 24px -12px rgba(1,14,11,.22)`.

## Tipografía

- Títulos: **Archivo** (500–700, ancho 75–100).
- Texto: **Public Sans** (400/500/600).
- Cifras/datos: **IBM Plex Mono** (400/500).
Todas con licencia SIL Open Font License (Google Fonts).

## Notas para la app

- Encabezado oscuro (ink) con el logo de Cloverance; contenido sobre fondo paper con tarjetas blancas.
- Los colores de madurez del conteo (verde, pintón, maduro, sobremaduro, seco) se mantienen por legibilidad, pero se armonizan con la paleta.
- Modo oscuro: fondo ink, tarjetas #0B1A16, texto paper.
